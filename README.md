# RELIC HUNTER V0.2.0 – Adventure Prototype

## Điểm mới
- Mở rộng world ngang lên thành một màn phiêu lưu dài hơn.
- Nhiều cụm Corrupted Slime.
- 1 Elite / mini-boss.
- Checkpoint: hồi HP và làm điểm respawn.
- Treasure Chest + coin reward.
- Boss Corrupted Forest Guardian giữ 3 pattern + Rage Phase 2.
- Sau khi hạ boss mở Exit Portal để kết thúc màn.
- Giữ mobile joystick + MOBA skill buttons từ V0.1.x.
- Giữ keyboard PC.
- Prototype art vẫn là runtime placeholder để ưu tiên gameplay.

## Chạy local
Không cần npm install.

```bash
npm run dev
```

Mở:
```text
http://localhost:5173
```

## Điều khiển PC
- A/D hoặc ←/→: di chuyển
- Space: nhảy
- J: combo 3 hit
- K: dash
- L: Crescent Slash
- R: restart khi clear màn

## Mobile
- Landscape.
- Joystick bên trái.
- Attack lớn bên phải.
- Skill, Dash và Jump dạng nút MOBA tròn.

## Luồng V0.2.0
START → enemy wave → checkpoint → enemy wave → elite → treasure chest → boss gate → Forest Guardian → Exit Portal → WORLD CLEAR.

## Art/Animation roadmap
V0.2.0 là bản gameplay prototype cuối cùng dùng placeholder art làm nhân vật chính.
Mốc tiếp theo đề xuất: **V0.2.1 – Visual & Animation Foundation**.

V0.2.1 sẽ thay KAI placeholder bằng sprite/animation thật:
- Idle
- Run
- Jump
- Fall
- Attack 1/2/3
- Dash
- Crescent Slash
- Hurt
- Death

Sau đó V0.3.0 mới tiếp tục Relic System.
